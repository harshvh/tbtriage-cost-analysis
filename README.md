TB TRIAGE+ cost analysis

R code accompanying the comparative cost analysis of two community-based tuberculosis active case-finding strategies — computer-aided detection of chest x-rays (CAD4TBv7) alone versus CAD4TBv7 combined with point-of-care C-reactive protein testing (CAD4TBv7-CRP) — implemented across South Africa and Lesotho (n=20,023).

The analysis takes a programmatic (provider) perspective, uses a bottom-up ingredients-based costing method, reports financial and economic costs separately in 2023 USD, annualises capital costs at 3%, and includes scenario and probabilistic sensitivity analyses.
